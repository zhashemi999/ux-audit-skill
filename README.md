
# UX Audit Skill

An AI agent skill for structured UX audits and actionable
usability recommendations.

## What it does

- Reviews user interfaces and product flows.
- Identifies potential usability issues.
- Prioritizes findings by severity.
- Suggests practical design improvements.
- Recommends ways to validate hypotheses.

## How it works

The skill provides a repeatable review workflow and a
structured output format for compatible AI agents.

## Current scope

This initial version is instruction-based. It does not
automatically collect analytics or conduct user testing.

## Future improvements

- Add annotated UX audit examples.
- Include a reusable audit report template.
- Add test cases to evaluate output consistency.
- Explore screenshot-based review workflows.
